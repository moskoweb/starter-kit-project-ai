# Localização

Locale base `pt-BR`, alternativa `en`. Cookie `locale` é lido no servidor e propagado aos componentes; root define `html.lang`. Datas usam Intl com timezone explícito onde necessário. Mensagens do shell vivem em `apps/app/src/lib/i18n`; componentes de auth/resources têm mensagens locais tipadas.

Novos componentes devem receber locale e mensagens, sem usar `window` durante render inicial para decidir idioma. Não traduzir IDs/códigos de API; mapear mensagens seguras para usuário. Resource gerado recebe `ResourceContext.locale`.

Provas locais: shell/lista/form/detalhe e login em inglês, theme persistido e drawer mobile. Textos de domínio dos projetos derivados são responsabilidade do produto; labels de campos gerados vêm da spec e podem ser personalizados.
