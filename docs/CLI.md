# CLI

Run local CLI through `pnpm exec tsx packages/cli/src/index.ts`.

- `create <dir> --profile personal|organizations|hybrid` copies source kit into a new directory and registers the profile's workspace panels with the same generator as `panel` (`apps/app/src/lib/panels/<id>.config.ts` + `registry.ts` import): `personal` → `app` (`/app`, context personal); `organizations` → `org` (`/org/<slug>`, context organization, `tenantIdentifier: "slug"`); `hybrid` → both. The template itself ships only the `admin` panel and no sample domain; build the domain with `resource`. When the kit is a git checkout, `create` writes `.vibe-kit.json` (origin URL, branch, commit) as the base for `upgrade`.
- `upgrade [--ref branch] [--preview] [--json]` runs inside a derived project (git repo, clean tree). It fetches the kit from `.vibe-kit.json` into remote `kit`, refuses when upstream changed an existing `packages/db/migrations/*.sql`, and three-way merges on branch `chore/upgrade-kit-<sha>` with `zdiff3` and `--no-commit`. The first run records the kit base as ancestor (`merge -s ours`, tree unchanged). Kit-only paths (`.planning`, `.mcp.json`) stay out; `.vibe-kit.json` advances. Resolve conflicts with `.agents/skills/upgrade-kit/SKILL.md`.
- `doctor` verifica estrutura, scripts e presença de configuração sem imprimir valores; configuração ausente retorna erro acionável.
`model Name --spec JSON [--preview] [--json] [--migration]` generates and registers a Drizzle schema. Inline spec: `{"scope":"personal|organizations|hybrid","fields":{"title":{"type":"string","required":true},"createdAt":{"type":"timestamp","default":"2026-01-01T00:00:00Z"}}}`. Supported types: string, text, integer, boolean, timestamp, uuid. Every generated table has owner identity and RLS. `personal` permits owner-only rows with no organization; `organizations` requires organization and membership; `hybrid` permits either owner-only or organization-member rows. Generator also writes `packages/db/scope-protections/<table>.sql`: database trigger rejects changes to owner and organization, including transitions between personal and organization scope. Preview writes nothing, including with `--migration`. Optional `--migration` invokes canonical generation immediately; otherwise run `pnpm db:generate` later. This development command requires CLI source, tsx and drizzle-kit; it generates schema migration first, then registered Drizzle custom migrations for pending protections. SHA-256 manifest in `migrations/scope-protections.json` tracks incorporated SQL; changed or missing incorporated sources fail closed. `pnpm db:migrate` refuses pending protections. Neither generator applies migrations or edits applied kit history.

Resource e painel: ver [CLI-RESOURCES.md](CLI-RESOURCES.md). Geração de projeto foi exercitada em diretório externo, com banco separado, autenticação e CRUD gerado. Preview e conflito de repetição também foram exercitados. Sincronização com o kit: `upgrade` (merge de três vias, nunca commita).

Configuração real é fornecida somente no projeto derivado. `.env.example` é preservado; `.env`, histórico `.planning`, caches e dependências instaladas não são copiados. Migrations do kit já aplicadas são imutáveis; `upgrade` recusa e exige escalonamento quando o upstream as altera.

Create also excludes Astro generated metadata, CLI lock directories and machine-local `.mcp.json`. Staging directories use exclusive random names; failed work removes only its own staging directory. Panel IDs containing hyphens before digits remain supported and generate valid, distinct TypeScript symbols.
